项目器材 :
	正点原子精英STM32F103开发板×1（自带蜂鸣器、led灯）
	FTF_LCD显示屏×1
	DHT11温湿度传感器×1
	DL-22 Zigbee模块×1
	L298N直流电机驱动模块×1（用于驱动风扇）
	12V风扇×1
	12V锂电池×1（用于直流电机驱动模块供电）
	导线、跳线以及面包板若干

系统描述:
	环境监测：
			温湿度：用于采集储衣间环境的温湿度，并将数据上传至协调器
	设备控制：
			1.风扇：手动|自动，湿度过高时自动开启风扇进行通风除湿，风速随湿度增加而逐级递增，防止储衣间衣服过潮而质量受损。
			2.照明灯（LED绿）：仅手动，用于照明。
			3.火灾预警灯（LED红）：自动，当发生火灾时（温度过高）自动闪烁。
			4.火灾警报器（蜂鸣器）：自动，当发生火灾时（温度过高）自动警报。
			注：上述设备运行状态可以通过协调器、微信小程序进行控制
