# 智能化服装仓储物联管理系统

- **技术架构**：FreeRTOS，ZigBee，RFID，MQTT，微信小程序，安卓App，Web

**项目价值**：针对服装批发企业，解决仓储盘点效率低、货品定位困难、环境控制滞后等问题，实现全流程数字化管理

**创新方案**：

•  **构建三层物联架构：**ZigBee协调器（主控中心）+终端节点（环境采集）+RFID读写器，实现仓储环境参数分钟级监测与设备控制

•  **搭建云端管理系统：**通过微信小程序、安卓App提供实时库存查询/智能补货预警/远程环境调控等功能

**贡献**：硬件的搭建与调试、FreeRTOS移植、网络数据传输
