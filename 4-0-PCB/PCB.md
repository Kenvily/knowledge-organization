# PCB

印制电路路板

软件：嘉立创

本质：元器件的支撑体，实现诸多电子元器件电气连接的载体

包含：基板+导线＋过孔＋阻焊+丝印+焊盘+安装孔

# PCB的层叠结构

## PCB单层板

基板+铜皮+绿油（阻焊）+丝印层

基板：绝缘的

绿油（阻焊）：盖住铜皮，防止触电，减少铜皮氧化

丝印层：属于PCB中的最上面一层，一般用于注释用。呈现方式为白色方框

## PCB双层板

元器件增多，单层板不适用。

过孔：从顶层切换到底层

丝印层+阻焊+铜皮+基板+铜皮+阻焊+丝印层

## PCB四层板

同等面积下，层次越多，可放置的器件越多

两层板+芯板+两层板

芯板：

## PCB六层板

两层板+芯板+两层板+芯板+两层板

通过过孔实现层与层的连通

## 其他

### 为何没有三层板等奇数板

可以实现，但没有必要。

制作过程中，会导致不必要的浪费，因为例如四层板和三层板（少印一层铜皮）成本差异不大。

双面材质不等则受力不均导致板翘弯曲变形

### 并非层数越多越好

层数并不是越多越好，两层就能画出来的证明布局和走线更顺、成本更低

# 通孔、盲孔以及埋孔

1. 通孔：打通顶层与底层的孔。
2. 盲孔：顶部与底部没有打通，仅打通了第一层与某一中间层。
3. 埋孔：打通内层之间的孔。

![jpg](.\img\kong-1.jpg)

本质都是用来换层的。

两层板不存在盲孔与埋孔

# 绘制封装

焊盘补偿：焊盘普遍比实际尺寸大小大，目的是为了方便焊接。

引脚的编号是一一对应的

对于丝印没有强制要求

封装必须精确

注意有的焊盘需要外扩，方便焊接，一般外扩0.2-0.3

原理图不影响实际使用，作为一种符号供人阅读的

封装是给实际画板焊接用，要对照实物，画焊盘，保证焊的上，大小合适

过孔：外径内径一样大时，为单纯的孔

过孔的外径会涂有铜，用于布线连接
